# PCMH-Roadmap

This repository contains a public-facing roadmap for Primary, Community and
Mental Health, presented across **Now**, **Next**, and **Later** delivery
horizons.

## Preview locally

Because the site is a simple static page, you can preview it locally by opening
`index.html` in a browser or by serving the repository with a lightweight HTTP
server, for example:

```bash
cd /path/to/PCMH-Roadmap
python3 -m http.server 8000
```
